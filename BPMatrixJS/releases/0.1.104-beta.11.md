# bpmatrixjs 0.1.104-beta.11

## 更新

- `Utils` 新增纯二维几何算法：`SignedDoubleArea`、`HasSeparatingAxis`、`ContainsTrianglePoint`、`SegmentDistanceSquared` 和 `TriangleOverlapArea`。
- 算法接收普通 `{ x, y }` 坐标，不依赖渲染器；三角形交叠面积支持两种顶点绕向，边界相切视为零面积。
- 导出 `Point2D` 和 `Triangle2D` 类型，供选择器及其他二维计算复用。

```sh
npm install bpmatrixjs@0.1.104-beta.11
```
