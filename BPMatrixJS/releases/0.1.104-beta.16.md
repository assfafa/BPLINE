# bpmatrixjs 0.1.104-beta.16

## WASM 布尔运算

- 新增 `bpmatrixjs/Utils/Bool`，使用 MIT 授权的 iOverlay / iTriangle；源码与依赖锁文件保留在 `Utils/Bool/src`，完整许可证随 npm 分发。
- `await Bool.ready()` 初始化后，同步调用 `Union`、`Difference`、`Intersection`、`Xor`。支持矩形、正多边形、多边形的连续轮廓，以及 Base / Text 三角网和混合输入；连续轮廓不需要预先三角化。
- 输入带 `id`、`type`、`data`，可传仿射 `matrix` 与 `metadata`。结果通过 `sourceId`、`sources`、`part` 和 `changes` 追踪合并、分裂与减空，输入保持不变。
- 单一无孔轮廓返回 poly；有孔或不连通的并集返回 base，保留全部内外轮廓。结果顶点以局部包围盒中心为零点，调用方须应用返回的 `matrix`。
- 增加独立的 `Intersects`（含接触）、`Overlaps`（正面积交叠）、`Covers` 与包围盒快速筛选 `FastCollision` / `GetBounds`。
- `build:lib` 顺序构建文字 WASM、布尔 WASM 和 TypeScript；产物携带内容哈希，浏览器与 Node 均支持加载。

## 验证

- 68 项测试通过，涵盖多孔、分裂、减空、自交轮廓、文字混合、变换、大坐标、来源追踪与连续运算。
- TypeScript、ESLint、库及浏览器构建、npm 产物检查通过；浏览器主线程及 Web Worker 加载验证通过。
- 发布到 npm `beta`，正式 `latest` 保持不变。
