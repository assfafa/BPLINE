# bpmatrixjs 0.1.104-beta.14

## WASM 字体与文字几何

- 字体注册、字形排版、曲线细分及 nonzero 三角化统一使用 C++/WASM，支持 TTF、OTF、WOFF、WOFF2。
- `RegisterTextFont(name, bytes)` 改为异步：必须 `await` 注册完成，再创建 `Text` 或调用 `CreateTextGeometry`。
- `GetTextFont(name)` 返回新的 `TextFont` 对象，使用 `shape(text)` 获取排版度量。
- 字形、排版、整段轮廓和填充模板复用有界缓存；返回的几何缓冲区彼此独立。替换或注销字体时释放资源。
- `Text.contours` 返回独立的真实边界与孔洞轮廓，供降级 Base 时使用，避免把三角化分段点暴露为编辑顶点。
- 原生源码位于 `Geometry/Wasm/src/text`；依赖与运行时许可集中保留在 `Geometry/Wasm/LICENSE`。

## 构建与打包

- `build:wasm` 构建原生模块；`build:lib` 先构建 WASM，再生成 TypeScript 的 JS 与声明文件。
- `prepack` 自动执行 `build:lib`，任一步失败都会阻止打包。npm 包包含配套 JS、WASM 与声明文件。
- `Geometry/Wasm/build` 为 Git 忽略的生成目录；依赖下载与编译缓存保留在项目挂载目录 `.local/wasm-text`。

```sh
npm install bpmatrixjs@0.1.104-beta.14
```
