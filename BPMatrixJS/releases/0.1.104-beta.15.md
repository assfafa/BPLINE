# bpmatrixjs 0.1.104-beta.15

## 原生竖排文字

- Text / TextOptions 增加 writingMode，支持 horizontal-tb 与 vertical-rl。每个输入行成为一列，列从右向左排列，字形使用 HarfBuzz TTB 定位。
- 竖排 textAlign 的 left、center、right 分别沿列顶、列中、列底对齐；对齐不会改变列的横向位置，支持半个字高的精确居中偏移。
- letterSpacing 沿文字流方向增加，lineSpacing 控制行间或列间距离。排版和几何缓存包含 writingMode。
- TextFont.shape(text, writingMode?) 返回对应方向的字形定位；竖排的 advanceWidth 表示列的前进长度。
- baseline 保持只选择 anchorY，全部几何仍以可见包围盒中心为局部零点。

## WASM 同步与验证

- 构建生成 WASM 内容哈希；浏览器请求携带哈希，避免原生接口变更后继续读取旧二进制。Node 文件加载保持直接读取本地模块。
- 51 项测试通过，包含竖排列对齐、稳定列坐标、切换布局与基线锚点；类型、Lint 与构建通过。
- 发布到 npm beta，正式 latest 不变。
