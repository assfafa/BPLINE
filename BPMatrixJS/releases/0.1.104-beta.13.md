# bpmatrixjs 0.1.104-beta.13

## 几何精度与通用算法

- 延续 beta.12 的单轮廓 nonzero 填充：简单凹多边形用耳切，自交、接触和反向路径用原生 X 带分解；填充交点不影响原始边框、线与关键点。Poly 不新增独立孔或 evenodd 填充选项。

- 矩形填充、圆角边框、线框和关键点统一接收 `precision`；`Rect` 保留 `originPrecision`，修改精度会重建相关缓存。
- 字体轮廓增加 `precision` 与基准精度，曲线误差随精度调整；排版位置和包围盒中心保持一致。
- 多边形圆角节点保留各自的分段精度，渲染库可以按相机倍率调整曲线。
- `Utils` 新增 `TransformPoint2D`、`InverseTransformPoint2D`、`ProjectSegmentPoint`、`ContainsPolygonPoint` 与 `CheckPrecision`。仿射坐标换算采用双精度；逆变换拒绝不可逆、非有限及溢出结果。点在多边形内的判定支持非零环绕与奇偶规则。

## 源码整理

- 类移到 import 后，字段及默认值、构造函数位于长方法之前；普通默认值直接在字段声明中初始化。
- `Rect` 和 `NGon` 的几何实现拆分为生成函数、轮廓计算及类型模块，保留原有公开入口。
- 维护目录增加 `agent.md`，包含文件说明、变量与默认值、函数、使用示例及中英文搜索关键词；构建后随对应 `lib` 目录发布。
- 增加目录说明生成、同步检查及共享 ESLint 规则，防止后续把主类和默认值重新埋入文件底部。
