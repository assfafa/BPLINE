# bpmatrixjs 0.1.104

## 二维几何与计算

- 发布 0.1.104 系列正式版，汇总本期 beta 的几何、文字及布尔运算能力。
- Utils 增加与渲染器无关的二维点、线段、三角形及平面计算，供选择、碰撞、吸附和编辑复用。
- Poly 支持凹轮廓、自交和非零绕组填充；保留连续边、边框和关键点数据。改进圆角与可调精度。

## WASM 文字

- 字体注册、排版、曲线采样和三角化使用 WASM，支持 TTF、OTF、WOFF、WOFF2。注册异步完成后，同步创建文字几何。
- 重复字形和相同排版复用有界缓存。支持换行、字间距、额外行距、横排及从右向左的竖列；按相应行或列对齐。
- 几何保持包围盒中心为局部零点，基线返回锚点；构建携带 WASM 内容哈希以保持接口与二进制同步。

## WASM 布尔运算

- `Utils/Bool` 提供 Union、Difference、Intersection、Xor，支持连续轮廓、三角网及混合输入，记录来源、分裂与减空。
- 无孔单轮廓返回 poly，有孔或不连通结果保留为 base；提供 Intersects、Overlaps、Covers、FastCollision 与 GetBounds。
- 原生依赖许可保留在对应 LICENSE 并随包发布；构建顺序为文字 WASM、布尔 WASM、TypeScript，消费者无需安装原生编译器。

## 安装

```sh
npm install bpmatrixjs@0.1.104
```

本版发布到 npm `latest`。对应 BPLineJS 正式版为 `0.1.104`。
