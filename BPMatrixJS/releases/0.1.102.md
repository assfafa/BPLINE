# bpmatrixjs 0.1.102

## 本次更新

- 整理 Rect、Poly、NGon 几何生成及 Vec2、Mat3 数学工具的控制流，提高可读性。
- 补充函数参数、返回值与调用示例注释，统一严格 TypeScript 和 ESLint 可读性约束。
- 保留矩阵与向量的版本通知机制、Mat3 的 WebGPU 对齐数据，以及几何体法线、边框和辅助点数据接口。
- 更新 Utils 工具的类型与注释；Time.now 可供控制器进行基于实际时间的运动计算。
- 发布 ESM 与 TypeScript 声明文件，支持根入口以及 Math、Geometry、Utils 子路径导入。

## 安装

```sh
npm install bpmatrixjs@0.1.102
```

这是不带 beta 后缀的版本。版本号仍处于 0.x，后续接口调整以具体版本说明为准。
