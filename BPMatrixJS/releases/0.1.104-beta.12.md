# bpmatrixjs 0.1.104-beta.12

## 更新

- `Poly` 对五角星等自交单轮廓按非零环绕规则生成填充三角面，不再把无法耳切的自交区域直接展开为三角扇。
- 自交点只加入填充几何；线、边框和关键点仍沿用户传入的轮廓生成。普通简单凹多边形继续使用耳切。
- 支持边界接触和反向重描的填充判定；三角面保持顺时针，UV 与原始包围盒对应。
- 本次实现位于项目源码，不为 `Poly` 增加 `libtess-ts` 调用。文字轮廓仍使用现有的 `libtess-ts` 依赖。

当前仍为单轮廓 `nonzero` 填充，不提供 `evenodd` 选项或独立孔洞轮廓。

```sh
npm install bpmatrixjs@0.1.104-beta.12
```
