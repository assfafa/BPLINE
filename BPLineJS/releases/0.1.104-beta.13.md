# bplinejs 0.1.104-beta.13

本文件保留早期准备记录；这些改动已汇总到实际发布的 [0.1.104-beta.14](0.1.104-beta.14.md)，不单独发布 beta.13。

## 更新

- 升级到 `bpmatrixjs@0.1.104-beta.12`：`Poly2D` 的五角星等自交填充遵循非零环绕规则，边框、线与关键点仍沿原始轮廓。
- 新增 `RectEditTool` 与 `RectEditToolKey`：矩形创建、点选和框选、移动、缩放、旋转、组模式、查看模式、触摸单指编辑、可配置快捷键及回调订阅。
- 编辑器支持世界原点步进、四角顶点吸附、轴向与等比约束、单选/多选、`activeOnly`、剪贴板、撤销/重做，以及 `save()` JSON 与 `load()` 回显。`Ctrl+S` 只触发 `save()` 和回调，不下载文件。
- 新增 `HelperGrid`：自适应网格、横竖标尺与日间/夜间/自定义颜色；编辑器默认启用。修复 Cent Browser 中标尺使用 `discard` 时整层消失的问题。
- `CameraControl` 增加 `oFDrag`、`tFDrag`，可分别控制单指和双指拖动；编辑器快捷键辅助类可协调左键与单指编辑。
- `Texture` 支持视频地址与 `HTMLVideoElement` 源，调用方可通过 `source` 控制播放、速度和跳转；渲染时上传当前视频帧。
- `Mesh`、几何体、材质与样式增加独立复制能力，样式类支持 `copy`/`clone`。

编辑器使用的 Phosphor SVG 图标遵循 MIT 许可，许可文本随 npm 包附带。

```sh
npm install bplinejs@0.1.104-beta.13 bpmatrixjs@0.1.104-beta.12
```
