# bplinejs 0.1.104-beta.17

## WASM 文字几何

- 依赖升级为 `bpmatrixjs@0.1.104-beta.14`，字体解析、排版、轮廓细分与三角化使用 WASM，支持 TTF、OTF、WOFF、WOFF2。
- 保留 `await Font.register(name, url)`；注册等待模块初始化与字体加载，之后 `new Text()` 和几何工厂同步生成数据，不使用后台 Worker。
- 相同字形及文字排版复用缓存，几何缓冲区保持独立。度量缓存包含字体注册版本，替换字体后重新计算。
- `Text.contours` 提供真实内外轮廓；文字降级 Base 时直接使用轮廓保留孔洞，避免三角化分段点成为额外编辑手柄。

## 案例与文档

- Example 升级两个库，文字案例与复制代码同步展示 WASM 注册、精度和多行文字；完整案例增加曲线精度控制。
- 修正数学库注册示例的 await 与返回类型，补充同步生成、缓存和轮廓 API 说明。
- 根 README 更新 beta 安装命令；站点重新构建到 docs，随提交部署 GitHub Pages。
