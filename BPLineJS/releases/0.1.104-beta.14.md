# bplinejs 0.1.104-beta.14

## 编辑器

- 新增 `RectEditTool`、`NGonEditTool`、`PolyEditTool`、`TextEditTool` 和集合 `Editor`。支持矩形边角编辑、正多边形内外圈、逐点创建多边形与沿边插点、开放折线、字体排版和原生文字输入。
- 集合统一选择、混合类型平移、组变换、历史、快捷键和文档保存。支持空范围组及任意父子层级；`nest` 控制普通实体互相嵌套，Group 始终允许接收子节点。
- 文字命中、吸附和手柄使用排版包围盒；首次点击选择，再次点击输入。退出输入删除空文字，保留文字独立撤销与剪贴板操作。
- 提供 `style` / `material` 联动模板、下一次创建的 `order`、`ignoreZoom` 和 `autoPrecision`。集合维护 `orderMax`；`raiseSelected` 临时提升选择，取消选择后恢复原 order。
- `snap` 总开关及顶点、边线、交点、网格分项控制吸附；移动、创建、改尺寸与旋转同步使用步进和屏幕距离候选。Shift 控制锁轴、等比及临时创建起点。
- 各功能开关默认开启；集合接管子工具的组与层级操作。`toBase()` 和 `onBase` 支持主动降级，自动异形降级与主动降级均可撤销为原几何类型。
- 具名事件 Map、`select()`、`selectAll()`、`push()`、删除、复制、撤销/重做和 `save()` / `load()` 可供代码调用。Ctrl+S 只返回 JSON 并触发保存事件。
- 修复圆角矩形反向拖边后丢失圆角、组反向缩放、文字旋转光标、混合选择无法联动拖动及嵌套后无法拖出的问题。缩放光标按边的屏幕空间法线适配方向。

## 相机与渲染

- 新增独立 `HelperGrid` / `HelperGridCustomStyle`：十进制自适应网格、主次线、独立网格/标尺 Mesh、默认开启的横竖标尺及日间/夜间/自定义配色；Color 原地修改与引用替换自动通知。
- `CameraControl.oFDrag` / `tFDrag` 分别控制单指和双指平移，与鼠标 `leftDrag` / `rightDrag` 独立，均遵循拖动总开关。编辑器键盘类只暂停左键和单指编辑的冲突操作，保留右键、双指及滚轮。
- `Texture.load()` 区分常见图片/视频地址，支持 `HTMLVideoElement` 作为 source；用户可控制播放、速度、跳转，Render 上传当前播放帧。
- Mesh、几何体与各 Style 分量提供 `copy()` / `clone()`；Mesh 复制时同时复制材质、参数、可变样式与原始 order，外部纹理保留引用，不复制 children。

- `CameraControl` 提供 `minZoom` / `maxZoom`（默认 `1e-13` 至 `999999999999`），限制滚轮、双指和惯性缩放；增加具名 zoom、position、rotation 和 change 回调。
- 标准 Shader 使用相机附近的局部锚点，改善高倍率缩放、平移时的边角精度；标尺在屏幕空间绘制，使用透明输出兼容 Cent Browser。
- `Scene.box = camera` 开启视口包围盒筛选，`Scene.quad = camera` 开启四叉树筛选，两者互斥，设为 `null` 关闭。四叉树根范围来自场景包围盒，`quadTreeDepth` 默认 2，支持主动 `quadTreeUpdate()`。
- `IMesh` 用一个整体包围盒筛选所有实例；`Mesh.culling = false` 可让屏幕辅助面或自定义 Shader 绕过筛选。资源管理及深度顺序仍由完整场景列表负责。
- `Mesh.autoPrecision` 按 `originPrecision * camera.zoom` 调整曲线，最低 3、最高 `precisionMax`（默认 100）；`Render.precisionDebounce` 默认 100 毫秒，设为 0 立即更新。固定屏幕尺寸的实体采用基准精度，自动细分不改变 NGon 边数。
- 编辑器构造时默认启用场景 box 筛选，新建实体默认启用自动精度。`Mesh.ignoreZoom` 及选择器、编辑框和吸附均按实际显示尺寸计算。
- `TextSelectTool` 与 Select 的 Text 结果按排版矩形拾取；`SelectCaret()` / `locate()` 返回零起始行列和 UTF-16 插入下标。辅助 Mesh 通过 `noSelect` 排除拾取。
- Base2D 可显式提供或从规则三角网提取内外轮廓，自动生成样式边框和关键点；仅编辑边界，支持拖点与沿边插点，不显示内部剖分节点。

## 文档、案例与署名

- Example 对齐本期两库版本，完整记录四个独立编辑器及集合入口、快捷键、保存文档、HelperGrid、TextSelectTool、QuadTree 和对应渲染/相机/场景/网格 API。
- 案例分别归入选择器、编辑器、辅助分类；编辑器仅提供集合案例，辅助网格单独展示。简洁与完整代码均为可复制运行的独立 TS 入口，包含 Render、Camera、帧循环、尺寸同步和销毁；完整版明确包含 CameraControl 和 GUI。
- 根 README 更新编辑器、渲染和辅助能力说明、中英文检索关键词、beta 安装命令及 Phosphor SVG 图标库的 MIT 署名；原许可文本随 npm 包保留。

## 源码与包结构

- 升级到 `bpmatrixjs@0.1.104-beta.13`，复用双精度坐标转换、线段投影及多边形包含算法。
- 主类、字段默认值和构造函数统一移到 import 后；矩形移动、改尺寸、组变换，以及 NGon/Poly 变换逻辑拆分到独立模块，通过实时 hooks 共享状态。
- 维护目录增加 `agent.md`，包含文件结构、变量、函数、案例、注意事项及中英文搜索关键词。目录说明随 `lib` 发布；本地案例和字体资源不进入 npm 包。
- 增加目录说明生成/同步检查，以及主类位置、字段默认值和可读性 ESLint 规则；清理原有 NGon/Poly 规范错误。

## 验证与发布顺序

两个库的 TypeScript、ESLint、目录同步检查和库/应用构建通过。41 项 Node 测试及 49 项浏览器行为检查通过，包含混合平移、降级撤销恢复类型、自动精度上限、空间筛选与 GPU 初始化。

先发布 `bpmatrixjs@0.1.104-beta.13`，再发布本包；两者均使用 `--tag beta`。

```sh
npm install bplinejs@0.1.104-beta.14
```
