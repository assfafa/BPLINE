# bplinejs 0.1.104

## 选择、编辑与场景

- 发布 0.1.104 系列正式版，依赖同步升级到 `bpmatrixjs@0.1.104`。
- 集合选择器统一几何、边、顶点与文字选择，支持多种选区形状及渲染顺序排序。
- Rect、NGon、Poly、Text 与集合编辑器提供鼠标/触控编辑、分层嵌套、组变换、步进、四类吸附、剪贴板、撤销重做、JSON 保存加载和主动降级为 Base2D。
- 集合编辑器接入 WASM 并集和减法，保留来源、样式、层级与撤销记录；增加快捷键 Tips。
- Mesh 包围盒、ignoreZoom、视口筛选、场景四叉树、自动精度及上限/防抖；相机控制器支持独立鼠标与触控开关、zoom 限制和事件监听。
- 独立 HelperGrid 提供随缩放调整的网格、标尺与日间/夜间/自定义配色。

## 纹理、离屏与后处理

- 纹理支持视频 DOM。新增 RenderTarget，材质与多纹理具名值直接接收目标，尺寸跟随相机 viewport。
- PostProcess 顺序执行共享 Render 的通道，提供 WgslPass、Bloom、Shadow、SMAA、FXAA。
- 发光和阴影参数属于 Style，相同参数按值合批。Bloom 尊重遮挡，并在光晕重叠时保留最强的完整颜色；支持透明画面与 HDR 输出。
- Render 提供 auto/true/false HDR 模式及对应状态和事件。普通材质颜色保持原值。
- 文字使用同步更新的 WASM 字体方案，支持正确的横排、竖排与对齐。

## 版本化文档与案例

- 网站按 `Example/package.json` 中的精确 bplinejs 版本构建到 `docs/<version>/`。后续构建只更新当前版本目录，旧版独立保留。
- 顶部下拉框切换版本根目录；支持保留共同页面，旧版缺失的页面回到该版本对应栏目首页。原有根地址跳到最新版本，兼容已有 hash 链接。
- 从 Git 标签恢复完整 `0.1.103` 网站；新正式版 `0.1.104` 包含本期 API 文档与全部在线案例。

## 安装

```sh
npm install bplinejs@0.1.104 bpmatrixjs@0.1.104
```

本版发布到 npm `latest`；库构建产物和本地验证文件继续排除在 Git 提交之外。
