# bplinejs 0.1.104-beta.11

## 更新

- `Mesh.bounding` 默认关闭；设为 `true` 后，`boundingBox` 按需返回 `{ local, world }`，每个范围包含 `x`、`y`、`width`、`height`。`x/y` 为最小坐标，几何或变换变化时自动重新计算；关闭、无有效顶点时返回 `null`。包围盒只包括 Mesh 自身的已生成顶点及线框，不包括子节点。
- 新增 Rect2D、NGon2D、Poly2D、Base2D 的点选与面积选择器，以及边和顶点的屏幕像素半径点选。`Select` 统一返回分组结果，可用 `Select.Sort(result, "asc" | "desc")` 按渲染顺序整理 Mesh。
- `Select.Selector(mesh)` 接受 Rect2D、Poly2D、NGon2D 作为选区；`all/left` 要求完整覆盖，`any/right` 接受相交或相切。凹多边形和带孔正多边形按实体三角面判断。
- `CameraControl.leftDrag` 与 `rightDrag` 分别控制鼠标左右键拖动，同时受 `drag` 总开关控制；`leftDrag` 不影响触屏手势。
- 选择器复用 `bpmatrixjs/Utils` 中的二维几何算法，依赖 `bpmatrixjs@0.1.104-beta.11`。

```ts
mesh.bounding = true;
const bounds = mesh.boundingBox;

const select = new Select(scene, render, camera);
select.selectionMode = "right";
const result = select.Selector(selectionMesh);
const topFirst = Select.Sort(result, "desc");
```
