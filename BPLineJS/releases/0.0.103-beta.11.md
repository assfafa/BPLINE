# bplinejs 0.0.103-beta.11

## 本次更新

- 新增全局静态 `Font` 字体表：通过地址异步注册字体，按名称获取可调用的文字三角面生成函数。
- 新增 `Text` 几何体，支持换行、额外行距和字距、水平对齐、基线锚点，以及从上到下、从右到左的竖排。可见包围盒中心保持在局部 `(0, 0)`。
- 文字的填充、实体边框、轮廓线和关键点沿用 `Mesh` 与 `Style` 的统一设置方式。
- 依赖 `bpmatrixjs@0.1.103-beta.11`；更新公开入口、类型声明与文字渲染管线。
- 文档增加 Font、Text API 和可编辑文字案例；示例站点字体改用 WOFF2。

矩阵库不单独创建 GitHub Release，几何实现的版本说明见 [BPMatrixJS 0.1.103-beta.11](https://github.com/assfafa/BPLINE/blob/main/BPMatrixJS/releases/0.1.103-beta.11.md)。

## 安装与示例

```sh
npm install bplinejs@0.0.103-beta.11
```

```ts
import { BaseMaterial, Font, Mesh, Style, Text } from "bplinejs";
import fontUrl from "./MiSans-Normal.woff2?url";

await Font.register("MiSans", fontUrl);

const geometry = new Text("你好世界\n文字几何", 52, "MiSans", {
    lineSpacing: 12,
    letterSpacing: 2,
});
const mesh = new Mesh(geometry, new BaseMaterial(), false);
const style = new Style();
style.solid.enabled = true;
mesh.style = style;
```

这是 beta 预发布版本；正式版仍为 `0.0.102`。
