# bplinejs 0.1.103

## 更新

- 提供 `Font` 全局字体注册表和 `Text` 几何，支持 WOFF2、多行、间距、对齐和竖排。
- 新增 `CompositeMaterial` 的实体面、边框面、关键点面 WGSL 片段，以及 `WGSLMaterial` 的完整顶点与片元源码接口；未设置时使用有效的白色默认输出。
- 自定义材质支持具名 `number`、`Vec2`、`Mat3`、`Float32Array` 和多个 `Texture` 传值；同名纹理替换仅更新资源绑定。
- 新增直接传入三角形顶点的 `Base2D`；同尺寸更新复用 GPU 缓冲。
- `Style.key` 纳入 Pipeline 缓存键，相同样式与着色器状态可复用管线；`Style.type` 补齐对象类型。
- 依赖 `bpmatrixjs@0.1.103`。文档和交互案例随正式版更新。

```sh
npm install bplinejs@0.1.103
```

BPMatrixJS 的版本说明见 [0.1.103](https://github.com/assfafa/BPLINE/blob/main/BPMatrixJS/releases/0.1.103.md)。
