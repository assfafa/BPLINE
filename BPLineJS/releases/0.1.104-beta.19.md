# bplinejs 0.1.104-beta.19

## 文字对齐修复

- 升级 bpmatrixjs 至 0.1.104-beta.15，文字原文与 writingMode 直接交给 WASM 排版，修复竖排字符因横排行对齐而跨列的问题。
- vertical-rl 中 left=列顶、center=列中、right=列底；layoutText 保留为转置行文本预览，不再用于生成竖排几何。
- 字符拾取、UTF-16 下标、空行区域、原生输入面的方向与逻辑起止对齐同步使用竖排列布局。
- baseline 只改变 anchorY，顶点仍按可见包围盒居中。

## 案例

- 文字完整案例显示粉色锚点、anchorX/anchorY 数值，并增加长短行对比按钮；长竖列自动适配视口。
- 默认保留两行 Hello World；复制代码与效果同步，完整代码可在原生 TS 单页使用。
- 文字与此前 WGSL、视频、集合编辑器、网格的展示代码均不包含离页销毁流程；React 预览内部保留卸载清理。
- Example 使用实际 npm 新版本重新安装和构建，避免本地同版本替换留下旧预构建模块。

## 验证

- 数学库 51 项测试；24 组真实 MiSans 竖排布局检查覆盖列坐标、范围、字素、空白、克隆和锚点。
- 两库及 Example 类型、Lint 与构建通过。发布到 beta 标签，正式 latest 不变。
