# bplinejs 0.1.104-beta.18

## 视口查询防抖

- Render 新增 `boxDebounce`，默认 100 毫秒，设为 0 关闭；负值及非有限值会抛出 RangeError。
- 对 `scene.box` 的连续相机变化合并查询，独立于 `precisionDebounce`，不影响 quad 模式。
- 首次启用、更换筛选相机立即查询。等待期间使用完整有序列表，避免旧筛选结果漏画新进入视口、刚添加或移动的实体；停止操作后恢复 box 筛选。
- 关闭筛选或销毁 Render 清理计时器；延迟回调不覆盖当前正在显示的其他场景。

## 案例与主题

- 统一案例为透明 Render 背景，使用页面日夜主题底色；集合编辑器与辅助网格同步主题，切换时不重建场景或丢失编辑内容。
- 增加独立 WGSLMaterial 案例：简易版替换片元阶段，完整版演示顶点与片元、自定义传值及动画控制。保留 CompositeMaterial 案例。
- 图片贴图下新增视频贴图案例，使用 10 秒 Big Buck Bunny 片段，包含播放/暂停、进度、速度与循环；退出页面停止视频并释放资源。
- 两种新案例提供可复制的完整代码。Example 更新依赖并重新构建到 docs。

## 验证与发布

- 类型、Lint、目录说明、库构建以及 Example 检查与构建通过。
- 防抖验证覆盖首次查询、连续输入合并、等待期间新增实体、0 延迟、模式切换、销毁与参数校验。
- 继续使用 `bpmatrixjs@0.1.104-beta.14` 的 WASM 字体方案；文字多轮廓降级回归通过。
