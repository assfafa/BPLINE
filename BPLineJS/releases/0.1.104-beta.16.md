# bplinejs 0.1.104-beta.16

## Rect 创建起点与吸附

- 修复创建矩形途中缩放、平移或旋转相机时，按下起点随旧屏幕坐标漂移的问题。起点在按下时完成世界范围限制、步进及吸附，后续只按当前相机重新投影这个固定世界锚点。
- 预览框与松开后创建的实体共用定位结果，支持对角起点、center 起点、Shift 临时中心创建及 `ignoreZoom`。集合 `Editor` 的矩形入口同步生效。
- 修复未开启步进时拉框吸附被零比较距离挡住的问题。创建起点和终点支持顶点、边线、交点与网格吸附；开启步进时按屏幕距离取更近结果。
- 保持 add/sub 框选和自动组包围框的屏幕对齐方式；公共 API 和保存格式兼容。

## 案例与文档

- 集合编辑器完整案例增加 Rect 的 `origin` GUI 选项，展示对角或中心创建；可复制代码与实际案例同步。
- 更新 RectEditTool 与集合 Editor 的中英文说明，以及 README 的 beta 安装命令。
- Example 升级到本版本，重新打包至 `docs`，通过 GitHub Pages 部署。

## 验证

TypeScript、ESLint、目录说明同步、库构建与安装包检查通过。111 项浏览器回归检查通过，覆盖独立/集合入口、创建途中相机变化、center、ignoreZoom、四类吸附、步进择近及原有文字降级/撤销重做。41 项数学库 Node 测试通过。
