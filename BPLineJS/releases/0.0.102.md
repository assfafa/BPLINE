# bplinejs 0.0.102

## 本次更新

- 增加 CameraControl 的库构建入口和公开导出，支持鼠标拖动、可选右键拖动、滚轮焦点缩放及单指、双指触摸操作。
- 双指支持缩放、旋转、拖动；手势锁定触点 ID 后不被新增手指替换，坐标换算考虑相机父级变换。
- 控制器支持最近 100ms 运动采样、松手惯性和滚轮惯性，使用实际经过时间而非帧数计算；新增操作会中断旧惯性。
- 增加 rightDrag、inertia、damp、rotate 控制项及 dispose 监听器清理。当前 damp 默认为 0.3，表示每 100ms 保留 30% 动量；0 表示停止，正常范围为 0 到 1（不含 1）。
- 完善相机世界坐标、NDC、画布 CSS 坐标及浏览器视口坐标之间的转换，渲染器尺寸跟随容器。
- 统一源码 JSDoc、控制流注释与 ESLint 可读性规则。
- 更新 bpmatrixjs 依赖至 ^0.1.102，发布 ESM 和 TypeScript 声明；本地 Examples、开发证书不包含在 npm 包内。

矩阵库不单独创建 GitHub Release，历史更新请查看 [BPMatrixJS/releases](https://github.com/assfafa/BPLINE/tree/main/BPMatrixJS/releases)。

## 安装与控制器入口

```sh
npm install bplinejs@0.0.102
```

```ts
import { CameraControl } from "bplinejs";
// 也可以从 "bplinejs/Control" 具名导入。
// 单文件入口：import CameraControl from "bplinejs/Control/CameraControl";

const control = new CameraControl(camera, render);
control.rightDrag = true;
control.inertia = true;
control.damp = 0.3;

// 在已有动画循环中、render.render(scene, camera) 之前调用。
control.update();

// 不再使用控制器时清理监听器。
control.dispose();
```

WebGPU 需要浏览器支持以及 HTTPS 或 localhost 安全上下文。发布检查不代替移动端触摸手感、浏览器兼容性和性能实测。
