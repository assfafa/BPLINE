# bplinejs 0.1.104-beta.21

## 离屏渲染与后处理

- 新增 `RenderTarget(scene, camera, { format?, data? })`，尺寸取相机 viewport（物理像素）。`renderPass(target)` 提交离屏渲染，`warmupPass(target)` 只准备资源。
- 标准材质、CompositeMaterial/WGSLMaterial 的具名传值及 IMesh 图层直接接收 RenderTarget，无需传 `.texture`。处理方向、预乘 Alpha、附件复用、尺寸变化与释放，并拒绝同一目标同时读写。
- 新增 `PostProcess` 和 `WgslPass`：有序通道支持增删、重排、启停、降采样和多纹理输入；`process(input)` 返回结果，`render(input)` 处理后显示到 Canvas。共享原 Render 的设备，输入画面保持不变。
- 新增可直接 `add` 的 Bloom、Shadow、SMAA、FXAA。SMAA 为 1x Medium，官方查找表内嵌，MIT 许可随包分发。

## 对象效果与遮挡

- 发光设置归属 `style.bloom`，阴影设置归属 `style.shadow`，默认关闭。支持颜色、透明度、强度、阈值、半径，以及内外阴影、偏移和扩散。
- 相同效果参数按值合组，独立 Style 也能共享遮罩与模糊。支持普通 Mesh、IMesh 冻结快照、copy/clone 与编辑器 JSON 保存回显；修改效果不重建几何。
- Bloom 遮罩保留场景 order、深度和实例提交顺序。非本组对象按真实覆盖率遮挡下层贡献，保留半透明、圆角、纹理和自定义 Shader 的透明/丢弃行为。
- 不同组的光晕按强度与透明度处理后的亮度选择最强的完整 RGBA，再与来源画面合成一次。避免逐组累加或逐通道取最大值导致重叠变白。
- 外阴影位于场景实体后方、背景前方，兼容不透明背景；内阴影限制在对象轮廓内。

## HDR

- `render.hdr` 默认为 `"auto"`，按浏览器 `(dynamic-range: high)` 检测；`true` 请求 HDR，`false` 使用 SDR。不支持扩展输出时回退 SDR。
- `hdrAvailable` 表示浏览器检测结果，`hdrEnabled` 表示 Canvas 接受 `rgba16float + extended`；通过 `onHDR(key, callback)` / `deleteHDR(key)` 监听变化。
- 普通材质保持原来的 0–1 色值。HDR 下 Bloom 及后续颜色输出保留浮点高亮；SDR 下限制发光合成到 0–1。Canvas 配置和 GPU 数值检查不能代替物理屏幕亮度验证。

## 本地案例与验证

- `Examples/index.ts` 提供案例列表；包含各个预置、单次 WgslPass 高斯模糊，以及随机 Style 的 Bloom + SMAA 组合。案例显示 HDR 模式、检测状态和 Canvas 格式。
- 本地案例不进入 npm 或 Git。TypeScript、ESLint、目录说明检查、库及案例构建通过。
- GPU 检查覆盖离屏生命周期、效果合批/拆组、遮挡、半透明、圆角、自定义材质、混合实例、最强颜色合并、抗锯齿、HDR 高亮保留、尺寸变化和资源释放。
- 依赖继续使用 `bpmatrixjs@0.1.104-beta.16`。本版发布到 npm `beta` 标签。
