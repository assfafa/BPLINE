# bplinejs 0.1.104-beta.15

## 修复文字降级轮廓

- 修复 `Text` 通过 `toBase()` 或组内仿射变换降级为 `Base2D` 后，部分外轮廓和孔洞丢失的问题。MiSans 的“再”“单”“田”与英文 `B` 等字形均可完整保留多条边界。
- 三角网边界提取先抵消端点相同的共享边，再按共线节点拆分未配对的长短边，正确抵消 T 接点两侧的内部边。按 X/Y 排序及范围查询减少候选节点扫描。
- 降级保留原填充顶点和三角面索引；全部外环与孔环可生成独立边框和关键点，内部剖分节点不作为编辑手柄。
- 新增内部 `Geometry/BaseContours.ts`，同步源码目录说明。公共 API 和保存格式保持兼容。

## 验证与文档

- TypeScript、ESLint、目录说明同步和库构建检查通过。
- 84 项浏览器回归检查通过，包含多孔文字、旋转/镜像/仿射降级、Base 独立边框与关键点生成、撤销恢复原文字及重做恢复完整轮廓。
- 更新 Base2D 和 TextEditTool 的中英文说明，案例网站使用本版本重新打包至 `docs`。

依赖继续使用 `bpmatrixjs@0.1.104-beta.13`。本包发布到 `beta` 标签，正式 `latest` 仍为 `0.1.103`。

```sh
npm install bplinejs@0.1.104-beta.15
```
