# bplinejs 0.1.104-beta.20

## 集合编辑器布尔运算

- 升级 bpmatrixjs 至 0.1.104-beta.16，接入 WASM 并集与减法。选中 A 后按住 `-` 点击 B，执行 A−B 并保留 B；按住 `=` 点击 B，合并双方。
- Group、IMesh、开放路径和辅助对象不参与计算。Rect / NGon / Poly 直接使用连续轮廓；Base / Text 使用实体三角面，支持混合计算。
- 无相交的 A 保留原 ID 和参数化类型；单轮廓结果为 Poly2D，有孔或不连通的并集为 Base2D，保留全部内外边界。原始样式、独立材质、order 与 ignoreZoom 保持正确，未参与运算的后代保留世界姿态。
- 新增 `await editor.boolean(target, "difference" | "union")`、`booleanEnabled`、`booleanOperation`、`booleanBusy`、`onBoolean` / `onBooleanDelete`。事件携带原始输入、结果 Mesh 与数学库来源记录。
- 几何替换、分裂、减空和层级更新共享一笔撤销历史；支持重做与 JSON 保存回显。首次加载期间取消、销毁或输入改变不提交过期结果。
- EditorKey 增加可配置的 `subtractCode` / `unionCode`；松开、失焦与进入输入控件恢复临时状态，文字输入及浏览器 Ctrl+-/= 保留原生操作。

## 文档与案例

- Example 更新至两库最新 beta。集合编辑器完整案例增加可展开的中英文快捷键 Tips，覆盖模式、选择、布尔、约束、吸附、边数、剪贴板、撤销和保存。
- 新增 Bool 独立 API 页，说明混合输入、结果矩阵、孔与分片、来源追踪、交集/对称差、碰撞与覆盖谓词；同步 Editor / EditorKey 文档。
- 文档网站构建到根目录 docs，随 Git 提交供 Pages 部署。

## 验证

- 数学库 68 项测试及集合编辑器 10 组浏览器场景通过，覆盖分裂、多孔、多 A、Base 连续裁剪、真实字体、层级、快捷键、撤销回显和 GPU 提交。
- 两库与 Example 的类型、Lint、构建及 npm 产物检查通过。发布到 beta，正式 latest 保持不变。
